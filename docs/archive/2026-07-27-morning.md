The Nigerian Port Economic Regulatory Agency Bill is designed to address these systemic issues by establishing a single, powerful body to oversee economic activities in the ports. Such an agency would be responsible for setting tariffs, ensuring fair competition, resolving disputes, and enforcing standards, thereby bringing much-needed transparency and predictability to the sector. The call from maritime lawyers, who are intimately familiar with the legal and operational complexities of the industry, highlights the urgency of this reform. President Tinubu's administration has emphasized economic reforms and improving the business environment. Assenting to this bill would align with these goals, potentially unlocking significant economic benefits by reducing logistics costs, attracting foreign investment, and boosting trade. ### 2. Scriptc by Vercel: TypeScript-to-Native Compiler, No JavaScript Engine in Binary
**Source:** Hacker News

**What happened:** Vercel Labs has released `scriptc`, a TypeScript-to-native compiler that generates small, fast native executables without embedding a JavaScript engine like Node or V8. This "zero-runtime TypeScript" tool allows developers to compile ordinary TypeScript code, type-checked by the real TypeScript compiler, directly to native binaries. For example, a simple `fib.ts` program compiled with `scriptc build fib.ts` results in a self-contained native binary of approximately 178KB with a startup time of ~2ms, significantly outperforming Node.js (~47ms startup, 60-100MB binary size). `scriptc` operates in three tiers: statically compiled (native code, no engine), dynamically run (embeds a small QuickJS-ng engine for un-staticable code like npm dependencies), and rejected (fails with specific error codes). It supports a wide range of TypeScript language features and Node.js API surfaces, including `fs`, `http`, `https`, `fetch`, and npm dependencies (with `--dynamic`). The project emphasizes "JS-faithful" behavior, differential testing against Node.js, and memory safety.

**Deep Lore / Context:** This is a groundbreaking development for the "Global Tech, AI & Software Engineering" landscape, particularly for developers deeply invested in the TypeScript ecosystem, like our reader. TypeScript has cemented its position as a preferred language for robust web and backend development due to its type safety and developer tooling. However, a long-standing challenge has been the overhead of the JavaScript runtime (Node.js/V8), which can lead to larger binary sizes and slower startup times, especially critical for command-line interfaces (CLIs), serverless functions, or microservices where cold start performance is paramount. Existing solutions often involve bundling, tree-shaking, or using alternative runtimes like Deno or Bun, but `scriptc` takes a more radical approach by compiling directly to native code.

Vercel, known for its focus on performance and developer experience with Next.js and its serverless platform, is strategically positioned to drive such an innovation. `scriptc`'s ability to produce "small, fast native executables" with "no Node, no V8, no JavaScript engine in the binary" fundamentally changes the performance profile of TypeScript applications. The three-tier compilation approach (static, dynamic, rejected) provides transparency and control, allowing developers to understand what parts of their code are truly native. The impressive benchmarks against Node, Go, Rust, and Zig in terms of startup time, binary size, and memory usage highlight its potential to make TypeScript a viable choice for performance-critical applications traditionally reserved for systems languages. This tool could usher in a new era for TypeScript, expanding its use cases and significantly enhancing the efficiency of cloud-native deployments.
