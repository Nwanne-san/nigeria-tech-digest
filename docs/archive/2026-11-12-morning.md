**What happened:** Google Cloud has announced the preview of two new SQL functions, `ai.classify` and `ai.extract`, within the AlloyDB AI query engine. These functions, available via the `google_ml_integration` extension on PostgreSQL 18, allow developers to perform text classification and structured data extraction directly inside their operational databases using standard SQL. This integration brings Gemini world knowledge directly into the database engine, eliminating the need for complex application-side code, external model endpoints, custom prompt wrappers, and manual parsing. Key capabilities include single/multi-label classification, category descriptions, few-shot prompting, and flexible execution modes for `ai.classify`, and schema-flexible JSON extraction for `ai.extract`. AlloyDB addresses performance concerns with "smart batching" for AI functions, grouping inputs into optimized micro-batches for faster inference and reduced model token costs.
**Deep Lore / Context:** This innovation significantly advances the "escalating" **AI Model Competition and Enterprise Adoption** storyline by deepening the integration of AI capabilities directly into foundational enterprise infrastructure: transactional databases. Historically, leveraging AI for unstructured text data (like clinical notes, customer reviews, or invoices) stored in databases required cumbersome ETL processes, external API calls, and complex application logic. This "application-side loop" introduced latency, increased operational friction, bloated application code, and raised data compliance risks by moving sensitive information across network boundaries.
