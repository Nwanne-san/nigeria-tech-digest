### OpenAI Rolls Out Text Watermarking for ChatGPT/Codex in EU, API Opt-in

**Headline:** OpenAI will start watermarking ChatGPT’s text in the EU (TechCrunch, The Verge, The New Stack)

**What happened:** OpenAI has announced it will begin adding an invisible, machine-readable watermark to text generated by ChatGPT and Codex for users in the European Union (EU) over the coming weeks. This move is to comply with the EU AI Act's transparency rules, which mandate that AI-generated content must be identifiable. The watermarking system, called textGrain, subtly shapes the model's word choices to embed a pattern undetectable by human readers but identifiable by a detector. For developers using OpenAI's API worldwide, the watermarking feature is available as an opt-in, remaining off by default, allowing them to decide how it fits their transparency obligations.
